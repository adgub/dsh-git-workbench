Git 绿色包

解压后双击「打开.bat」。出现一个黑色窗口，接着系统浏览器打开界面。
关掉黑色窗口，程序就退出。不会安装，不会写注册表，不会改系统 PATH，也不会留在后台。
删掉整个文件夹，程序和它记住的项目列表就一起没了。

文件夹里有什么
  打开.bat          启动
  runtime\node.exe  自带的 Node，不用单独安装
  git\              便携版 Git。没有这个目录时，才会去用系统里已经能用的 git
  app\              页面和本机服务
  workspaces.txt    要扫描的目录，每行一个
  data\state.json   面板记住的项目、颜色和栏宽

第一次使用
  1. 用记事本打开 workspaces.txt，每行写一个仓库路径，或写一个里面有多个仓库的文件夹。
  2. 双击「打开.bat」。
  3. 左上角「选取项目」里会出现检测到的仓库。列表以外的仓库，用「手动添加」填绝对路径。

提交时用的名字和邮箱，用的是该仓库自己的配置，或你原来就已经有的 Git 用户配置。
这个包不会去改那些配置。

不要运行 Git 或 Node 的安装程序。git\ 和 runtime\ 放在文件夹里即可。
端口固定为 127.0.0.1:47321，只本机访问。若提示端口被占用，先关掉上一次没关的黑色窗口。
